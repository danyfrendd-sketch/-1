# Брокевиль: архитектура проекта

Этот репозиторий уже содержит прототип игры в одном файле `brokeville8_map_upgrade.html`. Чтобы проект удобно развивать на iPhone/Safari, его нужно разложить по смысловым блокам.

## Основная идея

- `index.html` — входная страница, UI-скелет, canvas и HUD
- `styles/main.css` — все базовые стили
- `src/` — игровая логика, по модулям
- `assets/` — графика, звук, иконки
- `docs/` — проектная документация

## Рекомендуемая структура

```text
/
├── index.html
├── brokeville8_map_upgrade.html   # legacy monolith, сохранён как источник
├── styles/
│   └── main.css
├── src/
│   ├── main.js
│   ├── game.js
│   ├── world.js
│   ├── npc.js
│   ├── economy.js
│   ├── ui.js
│   ├── save.js
│   ├── controls.js
│   └── map.js
├── assets/
│   ├── icons/
│   ├── sounds/
│   └── .gitkeep
├── docs/
│   └── architecture.md
└── README.md
```

## Как делить код

- `world.js` — карта, тайлы, здания, деревья, дороги
- `npc.js` — NPC, перемещение, диалог, взаимодействие
- `economy.js` — деньги, ларёк, цены, заработок, кредит
- `ui.js` — HUD, телефон, меню, чат, панели
- `save.js` — localStorage, загрузка и сохранение прогресса
- `controls.js` — управление джойстиком, клавиатура, touch
- `game.js` — игровая петля, анимация, update/draw loop
- `main.js` — точка входа

## Что важно

- Не удалять старый монолит сразу: он нужен как эталон и резервный источник.
- Сначала переносим в структуру безопасно, проверяя работоспособность.
- Для Safari/iPhone важна мобильная адаптация: `viewport`, safe area, touch events, PWA-режим.
- После структуры лучше добавить `manifest.webmanifest` и при желании `service-worker.js`.
