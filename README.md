# Брокевиль

Safari-friendly web build of the original game.

## Запуск

Откройте `index.html` или опубликуйте репозиторий через GitHub Pages. Для проверки на iPhone откройте опубликованный HTTPS-сайт в Safari.

## Структура

- `index.html` — исходная HTML-разметка игры.
- `css/style.css` — стили, вынесенные из исходного файла.
- `js/game.js` — исходная игровая логика, вынесенная в отдельный классический скрипт.
- `brokeville8_map_upgrade.html` — исходный файл для сравнения и отката.

## Совместимость с Safari

- Обычный `<script>` вместо `type="module"`: это сохраняет общий глобальный контекст исходной игры и избегает ограничений загрузки ES-модулей при открытии через `file://`.
- Сохранены исходная разметка, canvas, мобильный viewport и метаданные Apple.
- Сохранения используют `localStorage`; браузер может ограничивать их в приватном режиме или при очистке данных сайта.

## Важно

Это безопасный первый этап разделения: HTML, CSS и JavaScript отделены друг от друга, но внутренний JavaScript пока остаётся одним файлом, поскольку функции и состояние тесно связаны через общие переменные. Следующий этап — постепенное выделение `World.js`, `UI.js`, `Player.js` и других модулей с проверкой после каждого шага.
