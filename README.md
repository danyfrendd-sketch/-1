# Брокевиль

Это веб-игра для Safari/iPhone в формате HTML5 canvas.

## Структура проекта

- `index.html` — корневая страница
- `styles/main.css` — общие стили
- `src/` — основная логика проекта
- `docs/architecture.md` — план архитектуры
- `brokeville8_map_upgrade.html` — исходный монолитный прототип

## Текущее состояние

В репозитории уже есть старый прототип, а также каркас новой структуры. Теперь нужно постепенно переносить код в отдельные файлы, чтобы проект можно было развивать без гигантского однофайлового куска.
