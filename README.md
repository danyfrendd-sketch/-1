# Брокевиль

Safari-oriented web build of the original game.

## Запуск

Откройте `index.html` через веб-сервер или опубликуйте репозиторий через GitHub Pages. Для проверки на iPhone откройте опубликованный HTTPS-сайт в Safari.

## Структура

- `index.html` — разметка игры и порядок подключения скриптов.
- `css/style.css` — стили.
- `js/config.js` — базовое состояние, генерация мира и исходные данные.
- `js/UI.js` — управление, меню, взаимодействие и диалоги.
- `js/Renderer.js` — отрисовка мира и персонажей.
- `js/Vehicles.js` — транспорт, движение и столкновения.
- `js/Interiors.js` — помещения и действия внутри зданий.
- `js/Phone.js` — состояние телефона и экран приложений.
- `js/Map.js` — карта города.
- `js/Economy.js` — экономика, смена дня и дополнительные системы.
- `js/GameLoop.js` — игровой цикл и автосохранение.
- `js/game.js` — нетронутая цельная версия игровой логики для сравнения/отката.
- `brokeville8_map_upgrade.html` — оригинальный исходный файл.

## Важно про совместимость

Скрипты подключаются обычными тегами `<script>`, а не ES-модулями. Это намеренно: исходная игра использует общие глобальные переменные и функции, поэтому порядок подключения важен. Не переставляйте теги без проверки.

Сохранены исходная разметка, canvas, мобильный viewport и `localStorage`. В приватном режиме Safari или после очистки данных браузер может не сохранять прогресс.

## Статус проверки

Логика разделена по исходным границам секций и подключена в том же порядке. Это структурный рефакторинг с минимальным изменением игрового кода, но полноценный запуск в iPhone Safari ещё необходимо проверить после публикации через HTTPS. Если игра не стартует, верните в `index.html` исходный тег `<script src="js/game.js"></script>` — цельный файл оставлен как резервная версия.
